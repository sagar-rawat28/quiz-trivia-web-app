# Quiz Trivia — Final Colorful Edition

Full-featured dynamic quiz app (Exam + Practice modes).

## Modes
- **Exam Mode** — answers revealed only after you finish the whole test
- **Practice Mode** — instant correct/incorrect feedback after each answer

## Key Features
- Live questions (Open Trivia Database) + offline fallback
- **All Questions** panel — see every question in one frame and jump to any
- **Flag** questions for later review
- Unlimited **Skip**
- 3 Lives • 50/50 Hint • Pause
- Speed & streak bonuses • Achievements
- Player stats • Leaderboard
- Light / Dark theme • Sounds • Confetti
- Fully responsive • Ready for Netlify

## How to use All Questions
Click **📋 All Questions** (or press **M**) during a quiz → see full list → tap any question to open it.

## Deploy
Drag the folder to https://app.netlify.com/drop  
No build step required.
